# Python Module 00 - Python Fundamentals

## 📚 Overview

Python Module 00 introduces the fundamentals of Python programming. Through a series of practical exercises, I learned the core syntax of the language and developed problem-solving skills using Python's built-in features.

---

## 🎯 Learning Objectives

Throughout this module, I learned to:

- Understand Python syntax and indentation
- Work with variables and data types
- Use strings and string manipulation
- Implement conditional statements
- Use loops and iterations
- Write and call functions
- Handle user input and output
- Use basic Python modules
- Follow coding standards and good practices

Understanding how Python stores and manipulates data.

String creation, formatting, slicing, and manipulation.

Creating reusable pieces of code with parameters and return values.

Using:

Developing a solid foundation in programming using Python.
